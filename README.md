Block Blitz

Block Blitz is a browser-based block puzzle game built with React and Vite.

Features

- 8×8 game board
- Place blocks on the board
- Clear completed rows and columns
- Score tracking

Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

Getting Started

1. Clone or download this repository.

2. Open the "client" folder in your terminal.

3. Install the dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local URL shown in your terminal.
