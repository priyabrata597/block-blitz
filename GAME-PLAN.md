# BLOCK BLITZ - Game Plan

## 1. Basic Game
- Board size : 8 x 8 grid
- Three block pieces available at a time.
- No block rotation.
- Single-player puzzle game.

## 2. Block Plcement
- Select an available piece.
- Place it on the board.
- Every part of the piece must fit inside the grid.
- A piece cannot overlap an occupied cell.
- Invalid placement must be rejected.

## 3. Line Clearing 
- A completely filled out row is cleared.
- A completely filled out column is cleared.
- Multiple completed rows and columns can clear in one move.
- The cleared cells become empty again.

## 4. Scoring
- Award points for placing blocks.
- Award points for clearing rows and columns.
- Include bonus point when multiple rows and columns are cleared in a single move.
- Display the current score and personal best.

## 5. Game Over
- Chck whether any available piece can fit on the board.
- If no, available pieces can be placed, end the game.
- Provide an option to restart a new game.

## 6. Future Full-Stack Features
- User authentication
- Player dashboard
- Game history
- Backend score validation
- All-time leadership
- Responsive design and touch support.
